# 👗 Lôlo's Closet — E-commerce Oficial

E-commerce moderno e responsivo desenvolvido para a boutique de moda feminina **Lôlo's Closet** (Instagram [@loloscloset.com.br](https://www.instagram.com/loloscloset.com.br)).

---

## ✨ Principais Funcionalidades

- **Catálogo de Peças com Alta Definição:** Roupas exclusivas com seleção de cores, tamanhos e visualização em carrossel de fotos reais.
- **Destaques & Stories do Instagram:** Acesso rápido às categorias e políticas de **Sobre Trocas** e **Entregas 📦**.
- **Checkout Descomplicado (Guest Checkout):** Compra fluida e ágil gerando mensagem pré-formatada para o WhatsApp oficial e opção de **Pix Instantâneo (QR Code + Copia e Cola)**.
- **Minha Conta Sem Senha:** Salvamento opcional dos dados no dispositivo da cliente com preenchimento automático em compras futuras e histórico de pedidos.
- **Cálculo de Frete & Motoboy RJ:** Simulador de CEP integrado com ViaCEP e opção de taxa fixa de R$ 15,00 via Motoboy (Zona Norte / Zona Oeste RJ).
- **Botão Fixo Flutuante de WhatsApp:** Suporte imediato no WhatsApp oficial `+55 21 97231-0968`.
- **Mobile-First:** Navegação rápida, touch targets confortáveis e barra inferior adaptada para smartphones.

---

## 🚀 Tecnologias Utilizadas

- **React 18**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide React** (Ícones modernos)
- **Canvas Confetti**

---

## 🛠️ Como Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Compilar para produção
npm run build
```
